# Selenium Automation Framework

A Java-based UI test automation framework built with Selenium WebDriver, Cucumber, and JUnit.

This project is being developed as a hands-on automation practice project, with a focus on building a maintainable and scalable test framework using modern automation practices.

## Tech Stack

- Java 17
- Maven
- Selenium WebDriver
- Cucumber
- JUnit
- Git / GitHub
- SauceDemo (target practice)
